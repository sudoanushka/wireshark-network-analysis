8. Security/Cybersecurity Relevance:
Broadcasting ARP requests exposes network topology by signaling active local IP queries. 
Repeated unanswered ARP requests can indicate dead hosts, incomplete network discovery scans, 
or potential target probing within a LAN segment.

9. Key Learnings:
Demonstrates how Layer 2 devices query an entire local network broadcast domain (ff:ff:ff:ff:ff:ff)
using an unknown placeholder Target MAC (00:00:00:00:00:00) when attempting to map an IP address 
to a physical address.

10. Conclusion:

on the local network segment.
