# Wireshark-Network-Analysis
Practical network traffic analysis, using Wireshark, including packet inspection, protocol analysis, and traffic filtering.

Overview

This project demonstrates practical network traffic analysis using Wireshark. The purpose of the project is to understand how common network protocols operate at the packet level and to develop foundational skills in network monitoring, troubleshooting, and cybersecurity analysis.

The project covers DNS, HTTP, TCP, ICMP, and ARP traffic

Objectives
- Understand packet-level network communication.
- Analyze common network protocols using Wireshark.
- Learn and apply Wireshark display filters.
- Examine TCP connections and communication patterns.
- Analyze DNS queries and responses.
- Understand HTTP requests and responses.
- Investigate ICMP echo traffic.
- Examine ARP requests and replies.
- Develop practical network-analysis and cybersecurity investigation skills.

Tools Used

- Wireshark
- Kali Linux

Key Skills Demonstrated

- Network packet analysis
- Wireshark
- TCP/IP fundamentals
- Protocol analysis
- DNS analysis
- HTTP traffic analysis
- TCP handshake analysis
- ICMP traffic analysis
- ARP analysis
- Wireshark display filtering
- Basic network troubleshooting
- Security-focused traffic investigation

Learning Outcomes

Through this project, I developed a practical understanding of how different network protocols operate and how packet captures can be examined to identify communication patterns.

The project helped strengthen my ability to:

1. Capture and inspect network traffic.
2. Identify protocols within packet captures.
3. Apply appropriate Wireshark filters.
4. Examine packet headers and protocol fields.
5. Understand communication between network devices.
6. Analyze TCP connection establishment.
7. Investigate DNS resolution.
8. Interpret ARP and ICMP traffic.
9. Document technical observations in a structured manner.

Relevance

Network traffic analysis is an important skill in cybersecurity. Packet analysis can help security professionals understand network behaviour, investigate suspicious communications, troubleshoot connectivity issues, and support incident investigations.

This project focuses on authorized lab and personal network traffic only.

Disclaimer

All traffic analyzed in this project was captured from authorized environments, personal systems, or intentionally provided sample traffic. No unauthorized systems or networks were accessed or monitored.
